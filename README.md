# مكتبة الكونتنت

مكتبة مذاكرة بالعربي للكونتنت والكوبي رايتنج: مقالات عالمية متلخّصة ومشروحة، ومع كل مقال إزاي تطبقه وتمرين.

## عن المحتوى
- صفحة كل مقال **صفحة مذاكرة مكتوبة بكلامنا**: الفكرة، والخطوات، وإزاي تطبقها كفريلانسر في مصر، وتمرين. مش ترجمة للمقال.
- كل صفحة فيها اسم الكاتب والمصدر ولينك المقال الأصلي، وكل حقوق الأصل عند أصحابه.

## الموقع اتبنى إزاي
HTML و CSS عادي من غير أي framework. الصفحات بتتولّد بسكريبت Python محلي من ملف بيانات لكل مقال، وبتترفع هنا جاهزة.
